## 🧪 Featured Project: [ScholarSense](https://github.com/Dhruvi1326/scholarsense)
**Hybrid-Cloud Agentic Engine for Structured Research Auditing**

ScholarSense is an autonomous forensic auditor designed to extract and validate high-stakes technical data from scientific documentation.

- **Agentic Logic:** Engineered a decoupled **"Thinking vs. Acting"** loop using `<thinking>` tags. This forces the model to plan its logic before committing to JSON serialization, reducing hallucinations by ~30%.
- **Hybrid Orchestration:** Implemented a provider-switching engine that defaults to **Local Gemma 4 (via Ollama)** to preserve IP-sensitive data, with an automated fallback to Gemini for global validation.
- **Production Infrastructure:** Built with a **Scale-to-Zero** architecture on **GCP Cloud Run**, utilizing **FastAPI** for the backend and **Qdrant** for semantic conceptual discovery.
